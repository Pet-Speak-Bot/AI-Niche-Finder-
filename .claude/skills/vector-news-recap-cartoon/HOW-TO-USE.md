# วิธีใช้สกิล vector-news-recap-cartoon (การ์ตูนสรุปข่าว 9:16)

สกิลนี้ทำคลิปแนว "สรุปข่าว/สรุปดราม่า ใน 60 วินาที" แบบการ์ตูนเวกเตอร์แบน ตัวอย่างคือคลิปถ้ำหลวง (episodes/tham-luang)

## ติดตั้ง (ทำครั้งเดียว)
แตกไฟล์สกิล เปิดแอป Claude ไปที่แท็บ Code เลือกโฟลเดอร์สกิลนี้เป็นโปรเจกต์ แล้วพิมพ์ "อ่านสกิล"
(ถ้าเครื่องนี้ยังไม่เคยติดตั้งชุดติดตั้งเริ่มต้น ให้ติดตั้งก่อน ดาวน์โหลดได้ที่ tadmaipen.com/th/start)
ใช้บนมือถือ/iPad ได้ ส่งไฟล์เสียงในแชต แล้ว Claude จะส่งคลิปกลับมา
ขั้นตอนข้างล่างนี้ Claude ทำให้เองทั้งหมด แค่บอกหัวข้อและส่งเสียงมา

## ทำคลิปใหม่
1. เขียนบท 60 วิ ประมาณ 740 ตัวอักษร (ฮุค > ที่มา > ไทม์ไลน์ตามวันที่ > จุดพลิก > ตัวเลข/ข้อเท็จจริง > สถานะ > บทเรียน > คำถามชวนคอมเมนต์)
   บรรทัดแรกใส่แท็กเสียง เช่น `[ผู้บรรยาย เสียงผู้ชาย น้ำเสียงเล่าข่าว]` แล้วอัดเสียงใน ElevenLabs
2. สร้างตอนใหม่และถอดเสียงเพื่อเอาเวลา
```
bash tools/new_episode.sh ข่าวใหม่ ~/Downloads/vo.mp3
python3 tools/islands.py ข่าวใหม่              # ได้เวลาแต่ละช่วงพูด + ข้อความ
python3 tools/islands.py ข่าวใหม่ --split 7.9 16.6   # หาจุดเงียบสุดเพื่อแบ่งการ์ดซับกลางประโยค
```
3. แก้ `episodes/ข่าวใหม่/episode.js`
   - `C` = การ์ดซับ `[เวลาเริ่ม, 'บรรทัด1|บรรทัด2', 'ซับอังกฤษ']` ใช้ `{y:คำ}` = สีเหลือง, `{r:คำ}` = กล่องแดง
   - `S` = ฉาก `{t: เวลาเริ่ม, f: ฟังก์ชันฉาก}` เปลี่ยนฉากทุก 5-8 วิ
   - ชิ้นส่วนสำเร็จรูป: studioBG, roomBG, navyBG, forestScene (ป่า/ภูเขาหลายเลเยอร์), cliff (หน้าผา+ปากถ้ำ), person (ตัวละคร),
     counterCard (ตัวเลขวิ่ง), stamp (ตราปั๊ม), phoneChecklist (มือถือเช็กลิสต์), nodeTrail (เส้นทางเงิน), header, chip (ป้ายวันที่), ctaPill
   - เสียงเอฟเฟกต์: `sfx(เวลา,'pop'|'ding'|'check'|'stamp'|'alert'|'tick'|'drop'|'chip',ความดัง)`
4. ดูเฟรมตัวอย่าง: `node tools/snap.js ข่าวใหม่ 2 8 15 30` แล้วเปิด `episodes/ข่าวใหม่/build/snap/sheet.jpg`
5. เรนเดอร์: `bash tools/finish.sh ข่าวใหม่ "ชื่อคลิป"` ได้ไฟล์ (มีเพลง) + (ไม่มีเพลง) ใน `final/`
6. ปก: `node tools/cover.js ข่าวใหม่ 0 2.0 "ข้อความเหลือง" "ข้อความขาว"`

## ข้อควรระวัง
- ข่าวบุคคลจริงหรือคดีความ ต้องใส่คำว่า "ตามรายงาน" หรือ "ยังไม่มีหน่วยงานยืนยัน" และห้ามแต่งข้อเท็จจริงเพิ่ม
- คนจริงที่เสียชีวิตหรือเรื่องอ่อนไหว ให้ใช้สัญลักษณ์แทนการวาดหน้า
- เพลงประกอบ: ใส่ไฟล์เพลงที่คุณมีสิทธิ์ใช้ ชื่อ `music.mp3` ในโฟลเดอร์ตอน ถ้าไม่มีจะใช้ดนตรีเบาๆ ที่สกิลสร้างให้ (สกิลไม่ได้แนบเพลงมาให้ เพราะเรื่องลิขสิทธิ์)
